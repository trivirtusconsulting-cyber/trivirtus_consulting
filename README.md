# TRIVIRTUS Consulting

Responsive static website for TRIVIRTUS Consulting, with partner portraits, a custom finance hero image, company services, WhatsApp contact links, and prefilled Gmail compose links.

## Publish with GitHub Pages

The files in this folder are ready for the root of `https://github.com/trivirtusconsulting-cyber/trivirtus_consulting`. After the files are uploaded, select **Settings → Pages → Deploy from a branch → main → /(root)** and save. GitHub will show the published site URL after the first build.

No build step is needed; the site is plain HTML, CSS, and local image assets.
